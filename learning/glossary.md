# Glossary: Quick Lookup (A–Z)

The number in brackets is the file with the full explanation.

| Term | One-line meaning |
|---|---|
| **10-K / 10-Q / 8-K** | Annual / quarterly / important-event SEC reports (8-K item 2.02 = earnings) [9] |
| **52-week high/low** | Highest and lowest price over the past year [4] |
| **Accumulation** | Whether more trading volume happens on up days (buyers in control) or down days [11] |
| **Adjusted (non-GAAP)** | Results with "one-time" items removed by the company [1] |
| **Adjusted price** | Price history rewritten so splits and dividends don't look like price moves [9] |
| **ADV** | Average daily dollar volume: how much money trades per day [9] |
| **After-hours** | Trading from 4–8 pm ET; earnings reactions start here [4] |
| **Analyst rating** | Buy / Hold / Sell opinion from a bank or research firm [6] |
| **Anchoring** | Treating a past price as the 'right' price ("QCOM is usually 170"), even though the 'usual' price keeps moving [16] |
| **Ask** | Lowest price a seller will accept right now [4] |
| **ATR** | Average True Range: how much a stock moves per day on average [5] |
| **Backtest** | Replaying history to see how a strategy would have done [9] |
| **Base rate** | How often something happens normally, before any pattern is applied [10] |
| **Beat / Miss** | Result was better / worse than the analyst estimate [2] |
| **Beta** | How much a stock moves when the market moves 1%; above 1 amplifies the market [11] |
| **Bid** | Highest price a buyer will pay right now [4] |
| **Book value** | Assets minus debts: what the company is worth "on paper" [3] |
| **Breadth** | How many stocks take part in a market move; narrow = only a few giants [10] |
| **Buying power** | Money available to buy right now [7] |
| **Candle** | One bar on a chart showing open, high, low and close for a period [4] |
| **Capex** | Capital expenditure: money spent on factories and equipment [1] |
| **Capitulation** | A burst of panicked selling on very high volume; sometimes marks the low because the last sellers have given up [16] |
| **Cash account** | Can only use your own money, no borrowing [7] |
| **COGS** | Cost of goods sold: the direct cost of making products [1] |
| **Consensus estimate** | The average analyst prediction [2] |
| **Correlation** | How much two stocks move together [7] |
| **CPI / PCE** | Inflation measures; "core" leaves out food and energy; core PCE is the Fed's favorite [11] |
| **Credit spread** | Extra yield risky company bonds pay over safe government bonds; widens when investors are scared [10] |
| **Death cross / Golden cross** | 50-day MA crosses below / above the 200-day MA [5] |
| **Defensive / Cyclical** | Stocks people buy in any economy (utilities, food) / stocks that need good times (tech, travel) [10] |
| **Dilution** | New shares issued, so each existing share owns less [3] |
| **Diversification** | Spreading money across stocks and sectors [7] |
| **Dividend (ex-date)** | Cash paid per share; the price drops by about that amount on the ex-dividend date [9] |
| **Dividend / Yield** | Cash paid to shareholders / that cash as a % of the price [3] |
| **Downgrade / Upgrade** | Analyst lowers / raises their rating [6] |
| **Earnings call** | Management's call with analysts after the report [2] |
| **Earnings report** | Quarterly results: revenue, profit, guidance [2] |
| **Earnings surprise** | Actual result minus the consensus estimate, as a fraction of the estimate [15] |
| **EDGAR** | The SEC's free website of company filings; it has a live list of new filings [9, 15] |
| **EMA / SMA** | Exponential / simple moving average [5] |
| **EPS** | Earnings per share = net income ÷ shares [2] |
| **Exhibit 99.1** | The earnings press release attached to an 8-K filing [15] |
| **Exposure dial** | How much of the account the system keeps invested, based on market conditions [11] |
| **Falling knife** | A stock that's crashing; risky to buy mid-fall [5] |
| **Feature request** | Data or a number the idea lab wishes it had; the weekly engineer builds it [14] |
| **Fed funds rate** | The Federal Reserve's main interest rate [11] |
| **Float** | Shares available for public trading [3] |
| **Form 4** | SEC filing for an insider's purchase or sale; code P = open-market buy [9] |
| **Forward P/E** | Price ÷ *expected* next-12-month EPS [3] |
| **Free cash flow** | Cash generated minus capex [1] |
| **GAAP** | Official US accounting rules [1] |
| **Gap** | Stock opens far from the previous close, leaving a hole on the chart. News that comes out while the market is closed is usually all "used up" in the gap [4, 16] |
| **Git branch** | A separate copy of the code's history where changes are made without touching the running version [14] |
| **Gross margin** | Gross profit ÷ revenue: cents kept per $1 after making the product [1] |
| **Gross profit** | Revenue − cost of making the product [1] |
| **Growth / Value** | Fast-growing, often expensive companies / cheap, steady companies [10] |
| **GTC** | Good 'til canceled: an order stays open across days [7] |
| **Guidance** | The company's forecast for upcoming quarters; what moves prices is whether it was raised, kept or lowered [2, 15] |
| **Hindsight bias** | After the fact, the reason always looks obvious [10] |
| **Hypothesis** | Why an idea should work, written before testing, including what result would prove it wrong [14] |
| **Income statement** | Report of revenue, costs and profit over a period [1] |
| **Jobless claims** | Weekly count of new unemployment filings: the earliest job-market warning [11] |
| **Limit order** | Buy or sell only at your price or better [7] |
| **Liquidity** | How easily you can trade without moving the price [4] |
| **Look-ahead bias** | Accidentally using future information in a test, which makes results look too good [9] |
| **Margin account** | Can borrow money from the broker [7] |
| **Market cap** | Price × shares = the value of the whole company [3] |
| **Market order** | Buy or sell immediately at the best available price [7] |
| **Masking** | Hiding the company name and year before Claude reads old text, so it can't use hindsight [15] |
| **Moving average (MA)** | Average closing price over the last N days [5] |
| **Multiple testing** | Trying many ideas makes some look good by luck, so each extra test raises the bar [14] |
| **Net income** | Final profit after all costs [1] |
| **Net margin** | Net income ÷ revenue [1] |
| **OHLC** | Open, High, Low, Close [4] |
| **Operating income / margin** | Profit from the core business / as a % of revenue [1] |
| **Overbought / Oversold** | RSI above 70 / below 30 [5] |
| **Overnight trading** | Trading between the evening and the 4 am pre-market on special venues; thin, and prices often already adjust there [16] |
| **P/B** | Price ÷ book value [3] |
| **P/E** | Price ÷ last-12-month EPS: dollars paid per $1 of yearly profit [3] |
| **PEG** | P/E ÷ growth rate [3] |
| **Position sizing** | Deciding how much to buy so one loss stays small [7] |
| **Post-earnings drift** | Prices keep moving in the direction of an earnings surprise for weeks afterwards [12, 15] |
| **Pre-market** | Trading from 4–9:30 am ET [4] |
| **Pre-open news check** | Our 9:20 am rule: a planned buy that got major bad news after the plan was made is skipped [16] |
| **Press release** | The company's own announcement; for earnings, the first full statement of the quarter [15] |
| **Price target** | Analyst's expected price in about 12 months [6] |
| **Priced in** | The market already expects it, so the news doesn't move the price much [10] |
| **Pullback** | A temporary dip inside an uptrend [5] |
| **Random twin** | Same number of picks and exits as a strategy, but random stocks: the fairness check [14] |
| **Reaction day** | The first trading day that can react to a release: same day if before 9:30 am, else the next day [15] |
| **Real yield** | An interest rate minus expected inflation [11] |
| **Relative strength** | How a stock or group performs compared with SPY or its sector [10] |
| **Relative volume (RVOL)** | Today's volume ÷ average volume [4] |
| **Resistance** | A price "ceiling" where sellers show up [5] |
| **Revenue** | Total money from sales ("top line") [1] |
| **Reversal** | The trend actually changes direction [5] |
| **Risk-on / Risk-off** | Investors confident (buying stocks) / scared (buying bonds, gold, dollar) [10] |
| **Risk/reward** | Potential gain ÷ potential loss [7] |
| **Rotation** | Money moving from one sector or theme to another [10] |
| **RS rank** | A stock's past-year performance rank among all stocks, 1–99 [11] |
| **RSI** | Relative Strength Index, a 0–100 momentum score [5] |
| **Russell 1000** | Index of the ~1,000 largest US companies [8] |
| **Sandbox** | Rules that limit what AI-written code may do (math only: no files, internet or future data) [14] |
| **Sector** | Industry group (Technology, Energy, Healthcare and so on) [7] |
| **Self-improving loop** | Propose → test → keep what works → learn → propose better; each turn uses the last one's lessons [14] |
| **Settlement (T+1)** | Sale cash becomes usable 1 business day later [7] |
| **Shares outstanding** | All shares that exist [3] |
| **Short selling** | Borrowing shares and selling them, hoping to buy back cheaper later; profits when the price falls. Our system doesn't short [16] |
| **SIC code** | The SEC's industry code for a company, mapped to our 11 sectors [9] |
| **Signal study** | Do the stocks a rule picks beat the average stock over the next weeks? No stops or exits involved [14] |
| **Split** | One share becomes several smaller shares; not a real gain or loss [9] |
| **Spread** | Ask − Bid [4] |
| **Stop-loss** | Automatic sell if the price falls to your level [7] |
| **Support** | A price "floor" where buyers step in [5] |
| **Survivorship bias** | Testing only companies that still exist, which hides the failures [9] |
| **Trailing stop** | A stop-loss that moves up as the price rises [7] |
| **Treasury yield** | The interest the US government pays to borrow; rising yields pressure stock valuations [11] |
| **Trend** | Overall direction: uptrend, downtrend or sideways [5] |
| **Volume** | Number of shares traded in a period [4] |
| **Yield curve** | 10-year minus 2-year Treasury yield; below 0 (inverted) has often preceded recessions [11] |
| **YoY** | Year-over-year: compared with the same period last year [1] |
